# 开源许可与安全策略

Yearning 自 2017 年起坚持开源维护至今，致力于为研发与 DBA 团队提供安全可控的 SQL 审核与数据库变更治理能力。

## 双许可模式

Yearning v4 采用清晰的开源与商业双许可模式：

- **开源许可（AGPL-3.0-or-later）**：基于 **GNU Affero General Public License v3.0 or later** 开源发布。任何二次开发、修改版本或通过网络对外提供服务的部署，均须严格遵守 AGPL-3.0 协议义务（包括第 13 条向网络交互用户提供完整对应源码的义务）。
- **商业授权与企业支持**：如需闭源定制、去除 AGPL 传染条款、定制数据库方言适配、企业级架构咨询或专属 SLA 响应支持，请联系作者邮箱：**henry@yearning.io**。

## 安全漏洞披露策略

安全是数据库治理平台的生命线。如果你在使用 Yearning v4 过程中发现任何安全漏洞（包括权限绕过、隐私脱敏泄漏、加密缺陷或 SQL 注入问题），**请勿直接提交公开 GitHub Issue**，请第一时间通过以下私密渠道联系维护团队：

- **安全联系邮箱**：`henry@yearning.io`
- **GitHub Security Advisories**：在 [cookieY/Yearning](https://github.com/cookieY/Yearning/security) 提交私密安全报告
